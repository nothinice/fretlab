FretLab: похожие приложения, сильные идеи и наш следующий шаг
16 ноября 2026

РЕЗУЛЬТАТ ПОИСКА
Рассмотрена широкая выборка: три подробных обзора по 12 продуктов/репозиториев
и дополнительные тренажёры ниже. Это не гарантированно все приложения рынка.
Поиск fretlab на GitHub дал 59 совпадений имени/описания, включая форки,
прототипы и не относящиеся к гитаре программы. Репозитории не равны продуктам.
Основные точные кандидаты на увиденный пользователем проект:
https://github.com/felix-zailskas/fretlab — демо https://fretlab.studio/
https://github.com/simoz/fretlab — демо https://simoz.github.io/fretlab/
Также найдены Aaronv1983/fretlab и o-icho/fretlab; несколько форков не считались
независимыми идеями. Какой именно сайт видел пользователь, пока неизвестно.

КАК ПРОВЕРЯЛИ
Для GitHub прочитаны README и выборочные исходники, но приложения не собирались.
У Fret Science выполнены Play/Pause и смена подписей; у upScale открыты настройки
грифа и целей. Другие возможности подтверждены открытыми страницами и официальной
документацией. Платные функции и качество распознавания микрофона не тестировались.
Подробные ссылки и границы проверки находятся в трёх приложенных обзорах.
Популярность функции не доказывает её педагогическую эффективность.

ЛУЧШИЕ ИДЕИ ДЛЯ НАШЕЙ ПЕСОЧНИЦЫ

1. Видеть смену аккорда заранее.
Felix FretLab, Fret Science, upScale: текущие опоры, следующий аккорд,
общие ноты. Для нас C → F: C остаётся, E поднимается в F, G — в A.
Ученик сначала предсказывает ход, затем строит и сравнивает на слух.
Источник реализации preview:
https://github.com/felix-zailskas/fretlab/blob/main/src/theory/chordPreview.ts
https://fretscience.com/guides/jam-track-player
https://upscale.li/app/

2. Музыкальные эксперименты с небольшим числом решений.
Oolimo связывает аккорд с прогрессией, Fretwise — упражнение с выбранным
гармоническим материалом. Нам полезны «одна нота меняет качество»,
«одна мелодия — две гармонии», «сохрани мотив, измени окончание».
Результат каждого опыта слышен; ученик затем свободно продолжает на том же грифе.
https://www.oolimo.com/en/chord-progressions/matrix
https://github.com/csenkey/fretwise

3. Конструктор секвенций: рисунок + сдвиг + ритм + область грифа.
Fret Science описывает такой общий инструмент. Для нас сначала проверенные
шаблоны 1–2–3 / 2–3–4, пары терций, обратное движение, ритмические варианты.
Учебная задача — продолжить или изменить правило и выйти к заданному аккорду.
Полный конструктор требует отдельной разработки; ближайшие опыты фиксированные.
https://fretscience.com/guides/melodic-sequence-explorer

4. Сравнивать несколько расположений в той же области.
Guitar Scientist, Scaler, два разных FretFlow: ограничить струны/лады,
сохранить общий звук, сравнить варианты следующего аккорда. Самый короткий
путь по высотам не всегда самый удобный для руки; нужны проверенные формы.
https://editor.guitarscientist.com/tutorial/positions-panel
https://scalermusic.com/products/scaler-3/
https://github.com/iecg/fretboard-app
https://github.com/Lfrangt/fretflow-ui

5. Сохранять точное упражнение для возвращения и преподавателя.
Soundslice сохраняет фрагменты, Fretflip — редактируемые учебные страницы,
FretMonster — состояние грифа в URL. Нам нужны именованные трудные места
с темпом и задачей, а позже — ссылка на собственную сцену/урок.
https://www.soundslice.com/practice-guitar/
https://fretflip.com/
https://songnotes.net/tools/fret-monster

КУРС: ЧТО ВЗЯТЬ
Pickup Music: принцип → упражнения → музыкальный джем → цельное исполнение.
Leavitt остаётся методической опорой этюда/второй партии, Levine — мотива
и голосоведения. Сайты дают идеи интерфейса, а не заменяют проверку содержания.
Soundslice/Guitar Pro: работа коротким фрагментом и добровольный рост темпа.
iReal Pro: сопровождение, изменение тональности и состава звучащих партий.
Solo: задания по роли звука над аккордом; распознавание реальной ноты — отдельно.
Functional Ear Trainer: слышать ступень в тональном контексте и находить её.
https://help.pickupmusic.com/en/articles/10513997-understanding-class-types
https://www.guitar-pro.com/docs/gp8/audio/playback/speed
https://www.irealpro.com/learn/advanced-practicing-techniques/
https://www.solotrainer.app/
https://apps.apple.com/us/app/functional-ear-trainer/id1088761926

ДОПОЛНИТЕЛЬНЫЕ ПРОВЕРЕННЫЕ ОРИЕНТИРЫ
Solo — официальный сайт описывает четыре тренажёра, порядок интервалов над
аккордами, голосоведение, транспозицию и реакцию на сыгранные ноты. FAQ отдельно
ограничивает область: гармоническая визуализация без ритмической тренировки.
Для нас важны ограничения задания и роль звука; ритм сохраняем в самом курсе.
https://www.solotrainer.app/faqs-1

Fretonomy — официальный сайт и описание разработчика подтверждают разные
типы заданий; App Store описывает карту точности по ладам и статистику времени
ответа. Для нас: повторять конкретное слабое место. Не приравнивать скорость
экранного ответа к чистоте игры. Мобильное приложение лично не запускалось.
https://www.fretonomy.com/
https://apps.apple.com/us/app/fretonomy-learn-fretboard/id1279576225

Fretionary — на сайте описаны диатонические прогрессии, позиции, карты для
печати и объяснения типичных разрешений аккорда. Для нас: рядом с составом
дать «куда может перейти этот аккорд и почему». Каталоги не заменяют задачи.
https://fretionary.com/

FretMonster (Song Notes, David Pots) — открытая страница позволяет ограничить
струны/лады, включить трезвучия и передать настройки ссылкой. Это полезно
для одной конкретной учебной идеи и записи роликов.
https://songnotes.net/tools/fret-monster

Другой FretMonster на fretmonster.app — отдельный сайт: Scales/Chords/Triads/
Identify/Notes/CAGED, позиции и 3NPS. Связь с David Pots не установлена.
https://fretmonster.app/

Fretonator — открытая страница связывает гамму, её формулу, диатонические
трезвучия и выбранную фонограмму. Для нас важна музыка рядом с объяснением.
Смена стартовой ноты сама по себе не определяет лад без контекста.
https://www.fretonator.com/f/sharp/ionian

Fretboard Forever — публичная страница практики задаёт конкретный порядок
поиска нот на струнах и повторения без ошибок; есть интерактивный гриф.
Для нас: простая самостоятельная задача и понятный критерий вместо каталога.
https://fretboardforever.app/practice
https://fretboardforever.app/whats-new

Fretflip — авторские интерактивные диаграммы, текст/медиа, публикация страницы
по ссылке и печать. Это сильный ориентир будущего режима преподавателя,
который превращает состояние песочницы в задание курса.
https://fretflip.com/

ПОРЯДОК ПРИМЕНЕНИЯ
Сейчас: четыре коротких опыта; вопрос–ответ; аккомпанемент с правой рукой;
целый блюз; локальная запись дубля; музыкальный финал и понятная навигация.
Далее: полноценная карта «текущий/следующий аккорд» для произвольной прогрессии;
конструктор секвенций; сохранённые именованные фрагменты; ссылки на задания.
После проверки с учениками: адаптивная очередь слабых мест, больше авторского
репертуара, педагогическая обратная связь. Распознавание инструмента — отдельный
этап с измерением задержки и ошибок, а не автоматический судья музыкальности.

Идеи реализуем самостоятельно. Для возможного использования чужого кода нужно
отдельно проверить условия конкретного репозитория; публичная страница не
даёт разрешения переносить тексты, записи и базы аппликатур.
